# MindClimber — USA Edition

A mobile trivia climbing game: answer questions correctly to climb 30 steps. Play solo or online with up to 5 friends.

## What's inside
- `index.html`, `game.js`, `game.css`: the game (fully in English)
- `questions_data.js`: 936 English questions in 9 categories (easy / medium / hard)
- `Assets/`: avatars, logo, mountain backgrounds and flag images

## Categories
History & Mythology · Geography · Science & Nature · Arts & Literature · Entertainment & Pop Culture · Sports · Psychology & Human Behavior · Image Recognition (world flags) · ONLY USA

Facts were checked against trusted U.S. sources such as USCIS (2025 Civics Test), NASA, the National Park Service, NOAA, the Smithsonian, the Library of Congress, the Pulitzer Prizes, the Academy Awards, AFI, the American Psychological Association and official league records.

## Publishing on GitHub Pages
The asset folder must be named exactly `Assets` (capital A), because GitHub Pages is case-sensitive.
1. Upload `index.html`, `game.js`, `game.css` and `questions_data.js` to the repository root, replacing the old files.
2. Keep the existing `Assets` folder.
3. Settings → Pages → Deploy from branch `main`, folder `/ (root)`.
4. Open the site on a phone. On a desktop browser the game shows a "Mobile only" message by design.
